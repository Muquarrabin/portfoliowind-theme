A modern, ultra-fast personal portfolio WordPress theme powered by free Tailwind CSS.

== Description ==

PortfolioWind is designed to give freelancers, developers, designers, and creative professionals the fastest, easiest way to launch a high-converting digital portfolio.

Built from the ground up with zero bloat and pure vanilla JavaScript, PortfolioWind delivers blazing-fast performance without heavy external libraries or page builder dependencies. Non-technical users can launch their full portfolio in under 5 minutes using the zero-code 'PortfolioWind Studio' admin dashboard.

= Key Features =
* **PortfolioWind Studio Dashboard**: Configure your entire portfolio (hero, bio, skills, services, projects, education/resume, contact) from `wp-admin > PortfolioWind Studio` with zero code.
* **Modern Skill Cards**: Sleek proficiency badges with level indicators (Beginner, Intermediate, Advanced, Expert), accent glows, and smooth progress tracking.
* **Interactive Education & Career Timeline**: Distinct graduation and experience milestone cards with rock-solid responsive node alignment.
* **Fluent Forms Integration**: Clean, native styling for Fluent Forms with dark mode support, plus an instant native mailto fallback.
* **Built with Free Tailwind CSS**: Zero third-party runtime bloat; ultra-clean utility design tokens.
* **Dark / Light Mode**: Instant one-click toggle with localStorage persistence.
* **Instant Project Filtering**: Real-time client-side category filter without page reloads.
* **Elementor Canvas Ready**: Full compatibility with Elementor Full Width Canvas template for custom visual layouts.
* **Tiered Supporter & Pro Licensing**: Simple coffee donation unlock for watermark removal, plus commercial developer licenses.

== Installation ==

1. In your WordPress admin, go to **Appearance > Themes > Add New**.
2. Click **Upload Theme** and select `portfoliowind.zip` (or install in `/wp-content/themes/portfoliowind/`).
3. Click **Activate**.
4. Go to **PortfolioWind Studio** in your admin menu to enter your details, skills, projects, and contact channels.

== Frequently Asked Questions ==

= Do I need a page builder like Elementor to use this theme? =
No! The theme automatically renders a stunning single-page portfolio based on the fields you fill in `wp-admin > PortfolioWind Studio`. However, if you prefer visual page building, Elementor is fully supported.

= How do I remove the footer watermark? =
PortfolioWind is 100% free and open source. Watermark removal is completely free for everyone: simply check "Hide Author Watermark in Footer" in `PortfolioWind Studio > Supporter / License`! You can also support the author on Gumroad ($3+) if you wish to donate.

= Can developers add their own agency watermark? =
Yes! Freelancers and agencies delivering client projects can purchase a Pro Developer key ($10+ minimum) on Gumroad to unlock their custom agency branding ("Theme customized by [Your Name / Agency]") in the footer with full commercial rights.
